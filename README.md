# Enanos App

Aplicacion realizada con React Native y Expo.

## Instalacion

npm install

Crear un archivo .env con:

EXPO_PUBLIC_API_URL=http://localhost:3000

Ejecutar:

npm run web

## Funcionalidades

- Agregar enanos con nombre y edad
- Mostrar enanos con FlatList
- Eliminar enanos de la base de datos
- URL del backend configurable
